# TrekathonProject

## Project Overview

The Dashboard is a comprehensive React Native application designed for organizations to monitor, analyze, and interact with their key operational statistics. This dashboard provides real-time insights into critical areas such as travel, leave, attendance, expenses, and payroll.

## Features

- Interactive graph tiles for key statistics
- Real-time data synchronization
- Responsive design across devices
- Intuitive navigation system
- Dynamic filtering and trend analysis
- Dark mode support
- Customizable layout (grid/list view)
